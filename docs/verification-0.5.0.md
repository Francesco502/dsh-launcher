### 升级测试脚本修正

公开资产复验暴露测试脚本的竞争：PowerShell `Move-Item -Force` 替换事务记录时会短暂删除目标。300 次并发读写检查记录到 452 次文件不存在和 116 次拒绝访问；与产品相同语义的覆盖移动未产生读取空窗（高频争用时写入仍可能正常报占用错误）。

两份开发测试脚本改为 PowerShell 7 的 `File.Move(..., true)`，并记录助手 stderr、提前报告助手退出。修正后使用正式包的 8 个兼容升级/回滚场景和两条运行中升级路径均通过。此修正只影响测试脚本，不修改已发布 EXE 或移动标签；早期失败记录保留，不冒充通过结果。

最终原始证据包括 `.tmp-release-050/official-identity.json`、`official-atomic-043/results.json`、`official-atomic-044/results.json` 及正式包截图。下载资产和隔离配置保留在本地，不上传包含用户数据的验收目录。
