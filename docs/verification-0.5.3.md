# 0.5.3 发布前验收

日期：2026-09-16。

## 修复范围

系统 PowerShell、netstat、taskkill 和 cmd 从 Windows API 返回的系统目录定位，避免启动器继承的 PATH 缺少系统工具时停止和更新失败。保留进程身份校验、超时、更新事务和回滚逻辑，不改变用户配置格式。

## 本地门禁

- GNU / MSVC 各 66 项业务测试、6 项图标测试通过；常规测试中的 2 项显式忽略保持原规则。
- 新增回归检查系统命令路径为绝对路径、空 PATH 下 PowerShell/CIM 查询成功、自定义程序路径保持原样。
- fmt、两种工具链的 Clippy、正式构建、CLI 中文和退出码检查通过。
- 两种工具链各完成 100 次窗口生命周期检查，不透明绘制和组件释放通过。
- JavaScript 29 项通过；下载验证 7 项通过，覆盖离线、错误哈希、版本、架构、ZIP 越界及重复条目。
- 六个本地发布资产、便携包四文件白名单、版本资源、SHA-256 和 SBOM 校验通过；本地候选使用 `local-working-tree`，正式发布必须以远端构建与下载资产复验为准。
- `git fsck --connectivity-only --no-reflogs` 通过。

## 实际运行验证

独立便携副本使用 `test-isolated-port` 构建和 3081 端口，子进程 PATH 仅包含 Node.js 目录。旧版 0.5.2 对同一 DSH 副本执行停止，复现“无法查询进程命令行：无法启动本机查询命令：program not found”；新版成功停止并重新启动。

同一受限环境下，真实 DSH 从 `0.1.5-rc.2` 更新到 `0.1.6-alpha.1` 并恢复运行；HTTP 响应的 DSH 身份标记验证通过，最终停止成功。日常 3080 服务 PID 在整个独立验收前后保持不变。

## 证据边界

独立测试构建不作为公开发布资产。发布还需确认 GitHub CI / Release 成功、下载六资产身份一致、正式包自更新及日常安装验证。本轮不声称其他 DPI、本地显示、真实按钮 P95 延迟或模型对话通过；窗口定时器至截图耗时不等同于真实按钮延迟。

本地日志和私有安装验收资料保存在 `.tmp-release-053/`，不进入公开资产。
